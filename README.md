# Arcana RNG

Jogo web de fantasia mística com invocações RNG, personagens 3D colecionáveis e progressão passiva de essência.

## Recursos

- Oito personagens com raridades de 1 em 2 até 1 em 50.000.000.
- Protótipos 3D em tempo real com Three.js e React Three Fiber.
- Inventário apenas com personagens conquistados.
- Guia completo de probabilidades.
- Equipar personagem e título separadamente.
- Ganho passivo de essência baseado na raridade equipada.
- Auto-Roll permanente desbloqueável por 5.000 essências.
- Progresso salvo localmente no navegador.
- Interface responsiva para computador e celular.

## Executar localmente

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000`.

## Produção

```bash
pnpm build
pnpm start
```

Projeto preparado para implantação na Vercel.
